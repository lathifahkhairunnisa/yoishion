# Yoishion — Hijab Outfit Planner

Web app hijab outfit planner bergaya modern modest Gen Z dengan warna dasar maroon + butter yellow.

## Fitur
- Smart hijab outfit planner berdasarkan occasion, style, dan tipe hijab
- Modern modest curated looks
- Saved Looks memakai localStorage
- My Wardrobe: tambah & hapus item
- Hijab Color Matcher
- Surprise Me random outfit
- Responsive & fluid layout
- GitHub Pages ready, tanpa backend

## Deploy ke GitHub Pages
1. Extract ZIP.
2. Upload `index.html`, `style.css`, `script.js`, dan `README.md` ke repository.
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Save.
